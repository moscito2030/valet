# 建立賽事與賽段

賽事獨立保存名稱、前綴與共用地點，**可以沒有任何賽段**。賽段各自保存名稱、日期區間、名單、賽制、計分方式、編排、牌型、成績、判罰與收分／發布設定。各賽段分別計分，**不跨段累積**。

## 新建賽事

裁判從首頁按「建立賽事」，填賽事名稱、選填前綴與共用地點，即可儲存。尚未新增賽段時，清單顯示「尚未安排賽段」，日期顯示「日期未定」。

進入賽事主頁按「新增賽段」，選一般橋牌或 迷你橋牌、隊制或雙人賽，填賽段名稱與參賽名單。雙人賽再選 MP、CrossIMP 或 ButlerIMP，以及 Single Winner（合併排名）或 Double Winner（NS／EW 分別排名）。建立時不選具體賽程，先保存名單；進入賽段後再安排。

日期欄位分為「開始日期」與「結束日期（選填）」。單日比賽只需填開始日期；跨日比賽再填結束日期。

初賽、決賽等階段可分別新增；原有比賽的成績保留為原賽段，網址與收分連結不變。

## 共用地點與賽段地點

賽段預設沿用賽事的共用地點。新增時或在裁判「比賽資訊 → 賽段資訊」填寫賽段地點，即使用該地點；留空（或只輸入空白）並儲存，則沿用賽事共用地點，不需勾選。更改共用地點只影響仍沿用的賽段。

## 建立後統一設定圈數、牌數與賽程

建立賽段時不填圈數或每圈牌數，只保存基本資訊與名單，不產生牌號或桌次。此時顯示「待設定賽程」，不能收分、開始圈次或結束賽事。

裁判之後到「賽程編排與牌局管理 → 指定賽程編排」設定圈數與每圈牌數，選擇編排、預覽並套用。隊制賽與雙人賽都在此統一設定圈數、每圈牌數與具體編排。

## 名單與分組

「雙冠軍・全場共牌 Mitchell」支援 3–40 桌完整搭檔，最多安排與桌數相同的圈數。NS 固定，EW 每圈移往下一桌，末桌回第 1 桌；奇數、偶數桌都不跳桌。每圈全場使用相同的新牌組，各桌須備妥複製牌。NS 與 EW 分別排名，適用 MP、CrossIMP 與 ButlerIMP。建立時只選 Double Winner，之後在尚未收分時到裁判「賽程編排與牌局管理 → 指定賽程編排」套用。

雙冠軍建立表單分為 NS／EW 兩欄，兩組人數必須相同，名稱不可重複。既有未收分賽段在裁判介面套用雙冠軍編排時，名單前半分到 NS、後半分到 EW；套用前請看分組預覽。

隊制賽可匯入隊伍賽員名單，再記錄各桌實際上場姓名。入座名單匯入時，隊伍尚未收錄的姓名可一併新增，不必事先逐人建立。

## 規模與修改限制

| 賽制 | 參賽者上限 | 圈數上限 |
| --- | --- | --- |
| 雙人賽 | 80 對 | 圈數 × 每圈牌數 ≤ 1024 |
| 隊制賽 | 3–32 隊；奇數隊可輪空，隊數可被 3／5 整除時另有交錯循環 | 圈數 × 每圈牌數 ≤ 1024 |

每圈最多 16 副，總牌數依編排計算，不另設固定上限；特定編排另有適用圈數。圈數與每圈牌數可在尚未收分時隨編排重設，已有成績（含取消）後禁止重建。

共用資訊在賽事主頁修改；賽段名稱與日期在該段裁判「比賽資訊」的「賽段資訊」修改；新增賽段時也可指定開始與結束日期；結束日期留空表示單日，且不可早於開始日期。賽事主頁顯示各賽段的日期範圍，首頁日曆可選取各賽段區間內的任一天（包含起訖日），不同賽段之間的空檔不計入。空賽事沒有可篩選的日期。

## 刪除賽段與賽事

任一賽段都可單獨刪除，包含原第一賽段；其餘賽段不受影響。刪除最後一個賽段後，賽事的名稱、前綴與共用地點仍會保留，可以再新增賽段。若要刪除整場賽事，回首頁從登入身分選單選「刪除比賽」，輸入完整名稱確認。整場刪除會連同所有賽段一起刪除；刪除前先備份。

每位賽員的賽程牌數以「圈數 × 每圈牌數」計算，最多 1024 副；超過 512 副時編排介面會顯示警告，仍可繼續。輪空也計入圈數。對稱式五角對抗每圈 4 副，四小圈為每人 16 副，而非全部牌組的 20 副。

## 封存賽事

裁判登入後，進入賽事主頁，按「封存賽事」。封存涵蓋整場賽事及其所有賽段，資料、名單、成績與牌型都保留。

封存後，只有已登入的裁判能在清單中看到賽事並開啟內容。觀眾與賽務身分無法透過清單、原賽段網址或 API 讀取；收分裝置的專屬連結也不能取代裁判權限。裁判仍可查看、管理，並按「解除封存」恢復原本的可見範圍；原有牌型與成績發布設定不變。

封存無法收回觀眾先前已下載或已載入的內容；重新請求時會依封存權限檢查。封存與「已結束」不同：已結束的賽事仍可公開查看。

## 複製賽段

裁判進入賽事主頁，在上方操作列按「複製賽段」，先選擇來源賽段，再填寫副本名稱後確認。尚無賽段時，此按鈕無法使用。副本建立在同一賽事下，完成後留在賽事主頁，賽段清單會顯示新副本。

複製內容包含賽制、日期與地點設定、名單、賽程、牌型、成績、判罰、Swiss 公布紀錄及收分／發布進度。這是完整副本，不會自動清除成績或重新開賽。副本有獨立的賽段 ID 與網址，後續修改互不影響。

收分連結不複製，須由裁判在副本重新簽發；原連結仍只操作原賽段。副本操作紀錄從複製開始，記錄來源賽段及版本。封存狀態沿用所屬賽事，複製不會解除封存。每場賽事最多 32 個賽段的限制仍適用。


## 封存單一賽段

裁判可在該賽段的「賽程編排與牌局管理」按「封存賽段」。封存後，該賽段只對裁判顯示；觀眾、賽務與收分裝置連結都無法存取，其他賽段不受影響。成績、確認狀態與操作紀錄保留。裁判可從賽事頁面開啟已封存賽段，再按「解除封存賽段」。若整個賽事仍封存，解除單一賽段封存不會讓它對外可見。
