# 快速辦一場 MiniBridge

以下示範 **3 桌、6 對搭檔、NS／EW 雙冠軍、CrossIMP、3 圈、每圈 2 副**，共使用 6 副牌。

## 1. 建立名單

登入裁判身分，從首頁按「建立賽事」。選「MiniBridge 迷你橋牌」、「雙人賽」，計分選 CrossIMP；這個例子使用「不去除」頭尾分數。

填賽事名稱、日期與地點。在「排名與編排」選 Double Winner Mitchell／Skip Mitchell，分別填入 NS、EW 各 3 對搭檔，一行一對，名稱不可重複。**圈數可以先留空**，建立後會顯示「待設定賽程」。每圈牌數之後仍可調整。

## 2. 產生並核對賽程

進入賽事，開啟「裁判功能表 → 匯入／匯出 → 指定賽程編排」。設定 3 圈、每圈 2 牌，選 Double Winner Mitchell，按「預覽完整賽程」。

核對 NS 固定、EW 輪轉、每桌牌號及兩組名單，再按「確認套用賽程編排」。準備牌號 1–6 的實體牌，依預覽移動。若要線上檢討手牌，再匯入對應的完整牌型 PBN；純收分不必先有牌型。

## 3. 發出收分連結

在「俱樂部收分」啟用模式，使用所有手機都能開啟的部署網址，逐對產生 QR／專屬連結。每對拿自己的連結；不要把全場連結公開張貼。

指定輸入方，預設為 NS；EW 負責核對。到「圈次與發布設定」將第 1 圈設為進行中。

## 4. 打牌、輸入、確認

輸入方選牌號，填「一線／成局」、花色、莊家、實得墩數，檢查 NS 原始分後儲存。另一方確認本桌本圈所有成績。MiniBridge 一律無身價，不接受加倍、滿貫或 Pass。

裁判在「俱樂部收分」檢查全場確認狀況，填寫結算原因並按「結算並發布本圈」。正常結算後進入圈間休息，再手動開啟下一圈。重複到第 3 圈。

## 5. 結束與保留資料

核對各圈已結算、取消牌與更正處理完成，再將賽事狀態設為已結束。NS、EW 各自排名；同分並列。匯出成績與賽事資料 JSON 留存，需要完整備份時由網站管理者備份資料庫。

## 如果是 4 桌

- 打 3 圈：可選 Double Winner Skip Mitchell，依預覽在指定圈次跳桌。
- 打滿 4 圈：選 Double Winner Mitchell（共牌／中繼），依預覽安排共牌／中繼牌桌或準備複製牌。

不要只改桌數就沿用三桌移動方式；先讓所有賽員核對桌號、方向與牌組。
