# Swiss 隊制賽

Swiss 僅支援一般開閉室隊制賽，不適用三隊、對稱式五角對抗或米契爾式五角對抗。

## 設定與公布

1. 建立隊制賽名單，在尚未收分前，進入裁判「賽程編排與牌局管理」的 **Swiss 隊制賽**。
2. 選擇安排模式、圈數、每圈牌數及輪空 VP（預設 12）。設定會清除原有未收分賽程，改為逐圈公布。
3. 選擇編排圈次，按「預覽配對」，核對隊伍、對手、配對 VP 與牌號，再按「確認公布以上對戰」。
4. 收分後繼續安排下一圈。必須先完整公布前一圈，才能安排後一圈。

當圈安排：第 N+1 圈使用截至第 N 圈的成績。隔圈安排：第 N+2 圈使用截至第 N 圈的成績，因此前兩圈可在尚未收分時公布。

首圈固定依名單順序 1–2、3–4、5–6 配對；奇數隊由最後一隊輪空。已公布的首圈不會因這項規則變更而重排。隔圈安排的第二圈採同分配對並避開首圈對手。

後續配對使用已完成對戰累計 VP 加已結算輪空 VP，**不包含判罰**。在不重複對手的條件下，求解整體 VP 差距最小的完整配對；同分排序由賽事與隊伍識別碼穩定決定。奇數隊先依輪空次數較少、VP 較低的順序，選擇仍能讓其他隊伍完整配對的輪空隊。

圈數最多為偶數隊數減一，或奇數隊數。這是避免重複對手的必要上限，不保證所有歷史配對都可安排到此上限。若無合法配對，系統會停止並提示，不會自行允許重賽。每圈最多 16 牌；圈數乘每圈牌數最多 1024，超過 512 會提示。

## 尚未收齊時分批公布

選擇「保守分批公布」。未完成對戰以 0–20 VP 的可能範圍處理，不將缺分當成已確定的零分。只公布雙方都已收齊，且分數同時高於所有未收齊隊伍的可能上限、或低於所有可能下限的對戰；也會保留剩餘隊伍可以完成合法配對的方案。

可能暫時沒有可公布對戰；請等待更多成績。這種分批方式不保證與整圈收齊後一次配對的結果完全相同。輪空須等配對依據全部收齊才公布。未安排的隊伍是等待配對，不是輪空。

補齊成績後，再預覽並公布剩餘對戰。已公布的桌次與對手保持不變。圈次未完整公布時，不能手動設定為開打或結束整場賽事。

## 更正與限制

每次公布保留依據成績與版本，供裁判核對。觀眾只能取得已公布賽程與輪空安排，不會取得配對依據中的對戰 VP、累計分數或輪空計分快照；公布下一圈對戰不等於公開前圈成績。之後更正相關 VP 或清除成績，裁判面板會提示既有配對依據已變動，但不會自動重排。公布後不支援切換編排方式、撤回對戰或手動改配；請在確認前核對預覽。

輪空只記明確公布的一隊，待該圈收分完成才計入 VP，不計實打牌數與 IMP。觀眾在「圈次與對戰」查看已公布安排。

可搭配「圈次與裝置收分」中的大賽收分模式，每個桌號的開室／閉室各綁定一台裝置。使用裝置收分時，Swiss 只有在同場開閉室都完成確認（或已由裁判結算）後，才將該場 VP 作為確定的配對依據；只輸入、未確認的成績仍視為待收齊，因此也能保守分批公布。輪空 VP 需等該圈結算。公布配對會保留配對依據 VP，而逐副成績仍待裁判結算後公開。整圈未完整公布不可結算；強制結算也不會自動開啟尚未完整公布的下一圈。
