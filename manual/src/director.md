# 裁判收分、更正與結算

## 私下檢視未公開牌型

以裁判登入後，在「逐副成績」點按未公開牌型的鎖頭，即可在目前裝置檢視該副牌。同時顯示該副各桌已輸入的成績，包含俱樂部收分尚未結算的成績；這些成績可能尚未確認。此操作不會公開牌型或發布成績，其他觀眾仍受原本發布限制。可按「更新私下成績」重新取得資料，或按「關閉私下檢視」關閉；切換牌號、頁籤、賽事、登出或重新整理頁面也會清除暫時檢視。尚未匯入牌型時仍可私下檢視成績。

## 一般收分與更正

在「裁判功能表 → 裁判更正成績」選圈次、桌次、牌號，輸入合約、莊家、加倍、實得墩數與選填首攻，核對 NS 原始分再提交。迷你橋牌 表單改用一線／成局，不提供加倍。

實得墩數是莊家拿到的總墩數，例如 4♥ 做成應填 10，不是 0。一般橋牌全 Pass 使用 Pass 選項；迷你橋牌 不接受 Pass。

已登錄的牌會顯示原紀錄；修改後按「儲存更正並重算」。**紀錄說明、更正原因與匯入說明皆選填**，留空時系統記錄操作名稱，仍保留前後差異。判罰扣分、不平衡合約等另有原因欄，依介面要求填寫；圈次與結算操作自動記錄原因。

## 更正雙人賽搭檔姓名／名稱

裁判進入「賽程與牌局管理 → 搭檔姓名／名稱」，選擇搭檔編號，填寫名稱後按「儲存搭檔名稱」。名稱不可空白、不可與其他搭檔重複，最多 60 字。這會更新該對搭檔的顯示名稱，不會改動搭檔 ID、分組、賽程、既有成績或收分連結；已結束的賽段也可更正。操作紀錄保留修改前後名稱。此功能不是替換參賽者或重新編排。

## 取消與判罰

取消牌統一顯示 Cancelled。取消會計入已處理牌數，但不參與比較計分；要恢復需由裁判／賽務操作。賽員手機不能恢復取消牌。

「判罰調整」可指定參賽者與扣分數值，輸入的是該參賽者目前總扣分，重新設定會取代舊值，不是再加扣一次。隊制賽不平衡合約可分別指定 NS 與 EW 獲判合約；原紀錄保留，雙方 VP 加總不一定為 20。要一般更正或取消時，先撤銷該不平衡判罰。

## 裝置收分：俱樂部與大賽模式

裁判在「圈次與裝置收分」展開「裝置、QRCode 與輸入方設定」選擇模式。俱樂部模式僅雙人賽適用，連結跟著搭檔；大賽收分模式支援雙人賽與隊制賽，裝置留在桌上。請在收分前選定，啟用後須先停用才能切換，且收分後不能切換；切換會撤銷舊連結。

俱樂部模式逐對產生專屬連結／QR。大賽模式先設定賽程（Swiss 先公布首圈），再依桌號簽發連結；一般隊制賽開室／閉室分開簽發，交錯循環則以實體桌號為準。每桌共用裝置，指定方輸入後交給對方核對。這是同機交接，不是獨立身分驗證；連結只交給對應裝置。

輸入方預設 NS，也能改為 EW、編號較小或較大者；個別桌次的指定優先。大賽模式的分工是現場操作指引，同一裝置可執行輸入與確認。每圈確認依實際桌次獨立保存，一間房的確認不會代替另一間房。

在「圈次與裝置收分」開啟當圈。指定方輸入所有牌，另一方核對並確認整桌本圈成績。確認後選手端鎖定。裁判更正未結算桌次後，對手需要重新確認。

| 動作 | 條件與結果 |
| --- | --- |
| 開始第 N 圈 | 前圈已結算且本圈賽程已備妥，開放本圈收分；不能跳圈 |
| 暫停收分／繼續本圈 | 暫停選手輸入與確認，保留已有成績；恢復後繼續原圈 |
| 全桌確認完成 | 最後一桌確認時自動結算並發布排名，進入圈間休息；不自動換圈 |
| 提前結束本圈… | 列出待確認桌次及將取消的缺牌；裁判確認後一次結算。下一圈已備妥時合併開始下一圈，否則留在休息；最後一圈進入覆核 |
| 撤回本圈開始 | 僅限本圈尚無登分或處理紀錄，退回上一圈休息；第一圈退回尚未開始 |

自動結算接在確認提交的同一次儲存內，沒有額外定時掃描；一般結算與強制結算均保留操作紀錄。觀眾只看到已結算圈的成績；尚未結算時可看到收件進度。Swiss 若先公布下圈配對，會保留已確認對戰的配對依據 VP，逐副成績仍須結算。停用裝置收分會恢復一般模式的成績公開方式。

若舊賽段曾跳過結算，畫面列出前圈提示，可補結算或處理未完成桌次；補結算不移動目前圈次、不更換收分連結。須先補齊前圈結算，才可再開下一圈。

開始下一圈時，若已匯入牌型的隱藏牌群已完成全部預定對局，會集中提示「公開並進入下一圈」或「暫不公開，進入下一圈」。公開包含手牌、PBN 與雙夢家分析；排名已隨結算更新。判斷涵蓋整份賽程及牌群所有牌號，後續仍有人要打或賽程尚未排完時不提示。已下載的牌型無法收回；也可稍後在「賽程與牌局管理」公開牌型。

重新簽發某搭檔或桌次連結會使舊連結立即失效，不會解除已確認狀態。換圈後桌次連結自動取得新的參賽者與牌號，舊圈表單不能誤送。已結算的結果由裁判／賽務在後台更正，選手端仍不能修改。

## 成績覆核、定案與清除

最後一圈完成、所有安排圈次與結果齊全後，自動進入「成績覆核中」；俱樂部模式另須全部圈次結算。選手在此期間可向裁判提出更正，裁判仍可修改成績，觀眾成績依裁判設定的刷新間隔更新。

覆核完成後，裁判按「完成覆核並結束賽段」。已結束代表成績定案，不可重新開放、修改分數、扣分或清除成績。觀眾端保存已定案的公開成績快取，再次開啟時不重複下載同一版本；入口仍檢查可見性，名稱與公開設定變更會更新快取版本。

尚未定案時，「清除所有成績」要求輸入賽事／賽段名稱確認，會清除成績、扣分與俱樂部確認／結算狀態，回到尚未開始；名單、牌型、編排與專屬連結保留。操作有紀錄，但介面沒有一鍵回復，請先備份。

若顯示「成績已被其他操作更新」，重新載入並核對最新資料後再提交，避免覆蓋另一位裁判剛完成的修改。

### 取消單桌剩餘牌並確認

在「查看待處理桌次」的清單，每桌後方可按「取消缺牌並確認」；牌已收齊則顯示「裁判代為確認」。確認視窗會列出未輸入牌數；確認後只取消該桌本圈缺分牌，保留已有成績，並由裁判認可、鎖定本桌。已認可或已結算的桌次無法重複操作。若這是最後一桌，會自動結算、發布整圈成績並停在圈間休息；隊制大賽模式按開／閉室桌次分別處理。

裁判更正成績表單對未收分或已取消的牌不預選合約，須先選擇合約才能提交。「恢復取消前狀態」會還原取消前的成績；原本未收分，或沒有可還原的成績紀錄時，恢復為未收分，不會將表單內容當成合約。需更正時，請恢復後另行輸入並儲存。


## 清除單副成績，回到未收分

裁判／賽務可在「裁判更正成績」選定圈次、桌次與牌號，按「清除此副成績，回到未收分」並確認。只清除該桌該副的合約、首引與大牌點紀錄，重新計算排名；不影響其他桌或其他牌。原成績保留在操作紀錄。未收分不計入已處理牌數，與 Cancelled 不同。

俱樂部與大賽模式會撤銷本桌確認，重新輸入後須再次確認。已結算圈次不開放清除單副成績；賽段已結束不可清除；不平衡合約須先由裁判撤銷。清除不會自動更改目前圈次或圈間休息狀態。


收分進度依桌次分列，顯示已收牌數、輸入／確認搭檔與「待輸入」「待確認」「已認可」狀態。單桌取消剩餘牌並確認的按鈕在桌面版靠右，手機版獨立顯示於該桌資訊下方。

點按收分進度列的桌次或文字資訊，可開啟該桌成績核對視窗，查看每副合約、NS／EW 原始分、首引及已記錄的大牌點；未收分與取消牌也會列出。此視窗僅供後台檢查，不會確認、修改或公開成績。


## 裁判工具列

依序為「比賽資訊」「賽程與牌局管理」「圈次與裝置收分」「裁判更正成績」「判罰調整」「操作紀錄」。比賽資訊包含賽段資訊與給獎；參賽名單、人數與搭檔名稱位於「賽程與牌局管理」；開始、暫停、結算及完成覆核均在「圈次與裝置收分」。牌局發布與永久刪除賽段位於「賽程與牌局管理」。賽務身分仍只顯示原有權限允許的功能。

比賽尚未開始（第 0 圈）時，首頁「目前圈數」提示顯示「比賽尚未開始」。若已設定第 1 圈時間，另顯示「預計於 HH:mm 開始」（臺灣時間）；未設定時不顯示時間提示。第 0 圈本身不設定時間區間。

## 觀眾端自動更新

在「比賽資訊 → 觀眾端自動更新」設定基本刷新間隔（15、30、60 或 120 秒，預設 30 秒）。已開啟的頁面會在下次更新後套用。背景分頁暫停更新，連線失敗時延長間隔，賽段結束後停止自動更新。
