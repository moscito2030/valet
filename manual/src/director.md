# 裁判收分、更正與結算

## 私下檢視未公開牌型

以裁判登入後，在「逐副成績」點按未公開牌型的鎖頭，即可在目前裝置檢視該副牌。同時顯示該副各桌已輸入的成績，包含俱樂部收分尚未結算的成績；這些成績可能尚未確認。此操作不會公開牌型或發布成績，其他觀眾仍受原本發布限制。可按「更新私下成績」重新取得資料，或按「關閉私下檢視」關閉；切換牌號、頁籤、賽事、登出或重新整理頁面也會清除暫時檢視。尚未匯入牌型時仍可私下檢視成績。

## 一般收分與更正

在「裁判功能表 → 收分／更正」選圈次、桌次、牌號，輸入合約、莊家、加倍、實得墩數與選填首攻，核對 NS 原始分再提交。迷你橋牌 表單改用一線／成局，不提供加倍。

實得墩數是莊家拿到的總墩數，例如 4♥ 做成應填 10，不是 0。一般橋牌全 Pass 使用 Pass 選項；迷你橋牌 不接受 Pass。

已登錄的牌會顯示原紀錄；修改後按「儲存更正並重算」。**紀錄說明、更正原因與匯入說明皆選填**，留空時系統記錄操作名稱，仍保留前後差異。判罰扣分、不平衡合約、俱樂部結算等另有原因欄，依介面要求填寫。

## 更正雙人賽搭檔姓名／名稱

裁判進入「圈次與發布設定 → 搭檔姓名／名稱」，選擇搭檔編號，填寫名稱後按「儲存搭檔名稱」。名稱不可空白、不可與其他搭檔重複，最多 60 字。這會更新該對搭檔的顯示名稱，不會改動搭檔 ID、分組、賽程、既有成績或收分連結；已結束的賽段也可更正。操作紀錄保留修改前後名稱。此功能不是替換參賽者或重新編排。

## 取消與判罰

取消牌統一顯示 Cancelled。取消會計入已處理牌數，但不參與比較計分；要恢復需由裁判／賽務操作。賽員手機不能恢復取消牌。

「判罰調整」可指定參賽者與扣分數值，輸入的是該參賽者目前總扣分，重新設定會取代舊值，不是再加扣一次。隊制賽不平衡合約可分別指定 NS 與 EW 獲判合約；原紀錄保留，雙方 VP 加總不一定為 20。要一般更正或取消時，先撤銷該不平衡判罰。

## 裝置收分：俱樂部與大賽模式

裁判在「裝置收分」選擇模式。俱樂部模式僅雙人賽適用，連結跟著搭檔；大賽收分模式支援雙人賽與隊制賽，裝置留在桌上。請在收分前選定，啟用後須先停用才能切換，且收分後不能切換；切換會撤銷舊連結。

俱樂部模式逐對產生專屬連結／QR。大賽模式先設定賽程（Swiss 先公布首圈），再依桌號簽發連結；一般隊制賽開室／閉室分開簽發，交錯循環則以實體桌號為準。每桌共用裝置，指定方輸入後交給對方核對。這是同機交接，不是獨立身分驗證；連結只交給對應裝置。

輸入方預設 NS，也能改為 EW、編號較小或較大者；個別桌次的指定優先。大賽模式的分工是現場操作指引，同一裝置可執行輸入與確認。每圈確認依實際桌次獨立保存，一間房的確認不會代替另一間房。

在「圈次與發布設定」開啟當圈。指定方輸入所有牌，另一方核對並確認整桌本圈成績。確認後選手端鎖定。裁判更正未結算桌次後，對手需要重新確認。

| 動作 | 條件與結果 |
| --- | --- |
| 結算並發布本圈 | 全桌已收齊且經對手確認；發布成績後進入圈間休息，裁判再開下一圈 |
| 強制結算 | 填原因、確認提示；未確認桌次強制認可，缺分牌取消；已有下一圈安排才自動開圈，Swiss 另須完整公布，否則保持休息 |

結算原因至少兩個字。一般結算與強制結算均保留操作紀錄。觀眾只看到已結算圈的成績；尚未結算時可看到收件進度。Swiss 若先公布下圈配對，會保留已確認對戰的配對依據 VP，逐副成績仍須結算。停用裝置收分會恢復一般模式的成績公開方式。

重新簽發某搭檔或桌次連結會使舊連結立即失效，不會解除已確認狀態。換圈後桌次連結自動取得新的參賽者與牌號，舊圈表單不能誤送。已結算的結果由裁判／賽務在後台更正，選手端仍不能修改。

## 結束、重新開放與清除

所有安排圈次與結果齊全後才可結束賽事；俱樂部模式另須全部圈次結算。結束後要改成績，先重新開放。

「清除所有成績」要求輸入賽事／賽段名稱確認，會清除成績、扣分與俱樂部確認／結算狀態，回到尚未開始；名單、牌型、編排與專屬連結保留。操作有紀錄，但介面沒有一鍵回復，請先備份。

若顯示「成績已被其他操作更新」，重新載入並核對最新資料後再提交，避免覆蓋另一位裁判剛完成的修改。

### 取消單桌剩餘牌並確認

在裝置收分的當圈進度清單，每桌後方可按「取消本桌剩餘牌局並且確認輸入」。確認視窗會列出未輸入牌數；確認後只取消該桌本圈缺分牌，保留已有成績，並由裁判認可、鎖定本桌。即使牌已收齊但對方未確認，也可用此按鈕代為確認。已認可或已結算的桌次無法重複操作。操作會留下紀錄，不會結算、發布整圈或開始下一圈；隊制大賽模式按開／閉室桌次分別處理。

收分／更正表單對未收分或已取消的牌不預選合約，須先選擇合約才能提交。「恢復取消前狀態」會還原取消前的成績；原本未收分，或沒有可還原的成績紀錄時，恢復為未收分，不會將表單內容當成合約。需更正時，請恢復後另行輸入並儲存。
