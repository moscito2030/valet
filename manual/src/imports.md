# 匯入與匯出

裁判在「匯入／匯出」選類型，上傳檔案或貼上內容，先「驗證並預覽」，確認後再匯入。說明選填；整批資料驗證成功才寫入，不會只匯入前面幾筆。

使用 UTF-8，檔案最多 200,000 bytes。CSV 第一列欄位名稱區分大小寫；包含逗號的值要用雙引號包住。建議先從同一賽段匯出範本，再修改匯入。

## 最大牌號

在「匯入／匯出」頁籤設定「最大牌號」，按「儲存最大牌號」套用。填 0 表示牌號持續遞增；填正整數則超過後從牌號 1 重新顯示。這項設定只影響顯示牌號，各圈成績仍獨立保存。

## 可用格式

| 類型 | 用途與注意事項 |
| --- | --- |
| 成績 CSV | `assignmentId` 必須對應該賽段的桌次安排，不能用桌號代替；可混合 played 與 cancelled |
| 完整牌型 PBN | 所有牌號各一次、完整 52 張牌；尚未收分才能替換 |
| 各圈時間區間 CSV | 更新所列圈次時間；未列圈次保留，空值可明確清除 |
| 賽程編排 CSV | 每個所列圈次須完整；已收分圈次不可改動；雙冠軍需符合固定方向 |
| 隊伍賽員名單 CSV | 隊制賽使用；依 teamId 更新列出的隊伍名單，未列隊伍保留 |
| 入座名單 CSV | 隊制賽實際上場姓名；可將尚未列在隊伍名單的姓名一併加入 |

隊伍名單匯入不是新增隊伍功能。不能移除已記錄上場的賽員；入座與名單調整不會改變既有合約分。

## 成績示例

```csv
assignmentId,board,level,strain,doubled,declarer,tricks,lead,status
r1t1,1,4,H,1,N,10,,played
r1t1,2,,,,,,,cancelled
```

這是假設第 1 圈第 1 桌 ID 為 `r1t1`、且安排牌號 1、2 的例子；實際 ID 請從匯出檔案或賽事 JSON 取得。迷你橋牌 沿用相同格式，但只接受一線與成局線位。

匯入 played 的完整合約會恢復同筆取消成績；已設定不平衡合約的牌需先撤銷判罰。賽事結束後要先重新開放才能修改成績。

## 清空與備份

只有欄位名稱、沒有資料列的 CSV 不能用來清空成績。請使用裁判「清除所有成績」，核對名稱與影響再確認。

可匯出成績、編排、牌型及賽事 JSON。JSON 方便攜出設定與紀錄，但目前沒有網頁 JSON 還原按鈕，不能取代資料庫備份。

完整欄位、入座與隊伍名單範例，請參閱[匯入格式參考](import-reference.md)。

## Valet Review 的保存與匯回

輸出至 Review 後，「儲存至瀏覽器」依來源識別追加牌局。有時間資訊時保留較新的成績；成績不同但時間相同或不足時，需在對話框選擇保留本機或使用目前成績，確認前不寫入。舊分享不會覆蓋已知較新的本機成績，匿名分享也不會清除已存姓名。

Review 的 PBN 與 CSV 可成對匯回：PBN 保留牌局 ID 與來源，CSV 保留成績來源、更新時間與 迷你橋牌 標記。CSV 文字欄位會加上試算表公式防護，匯回自動還原。完整備份建議用 JSON（Review 上限 32 MB；PBN／CSV 仍為 2 MB）。本機資料最多 256 副、10,000 筆成績，另受瀏覽器容量限制；成功儲存的資料不會因超過檔案匯入的 2 MB 限制而無法重開。

迷你橋牌 在 Review 使用迷你橋牌最佳合約顯示。檢視器更換發牌者或身價時也會重新分析，計算期間不沿用舊 Par。
