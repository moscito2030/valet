# 設定賽程與牌局

## 選擇賽程編排

到裁判「匯入／匯出 → 指定賽程編排」，輸入圈數與每圈牌數。系統依人數與設定列出適用選項；若沒有預期的選項，先檢查圈數及總牌數。

| 編排 | 使用方式 |
| --- | --- |
| 全場同牌輪轉 | 各桌同圈使用同一組牌，需複製牌或安排共牌 |
| Mitchell | 奇數桌，NS 固定、EW 移動，最多桌數圈 |
| Skip Mitchell | 偶數桌，中途跳一桌，最多桌數減一圈 |
| Mitchell 共牌／中繼 | 偶數桌，最多桌數圈，依預覽處理共用牌組 |
| Double Winner Mitchell 系列 | 3–19 桌完整偶數對數，固定 NS／EW 分組，各組排名 |
| Howell／3/4 Howell | 依內建桌數與圈數表提供；以選單與預覽為準 |
| 隊制循環對戰 | 隊制賽，每場安排開、閉兩室，兩室交換方向 |
| 隊制循環對戰（每圈一隊輪空） | 3–31 隊奇數隊，完整一循環需隊數圈；每隊輪空一次 |
| 三／五隊交錯循環 | 隊數可被 3／5 整除；圈數分別為 2／4 的倍數；每個循環可重新分組 |

一般雙人編排維持合併排名；要 NS／EW 分開排名，必須選 **Double Winner** 版本。它不適用奇數對數。其他適用的編排可將缺席搭檔視為輪空，不建立虛擬成績。

## 奇數隊隊制賽

建立賽事時可先留空圈數。若已填圈數，奇數隊預設採兩室對戰、每圈一隊輪空。到裁判「匯入／匯出 → 指定賽程編排」可改用以下方式；必須在收分前完成設定。

**輪空循環賽：** 3、5、7 至 31 隊均可使用。每圈其餘隊伍兩兩對戰；完整一循環每隊遇過所有對手且輪空一次。可設定較少圈次，多於完整一循環則開始下一循環。輪空 VP 預設 **12**，賽前可設 0–20（最多兩位小數）。該圈所有實際桌次收齊後，輪空 VP 才計入排名；不建立假對手、不計 IMP、實打牌數或個人統計。清除所有成績也會撤回已計入的輪空 VP，保留設定。

**三／五隊交錯循環：** 隊數可被 3 整除時可選三隊模式，總圈數須為 **2 的倍數**；可被 5 整除時可選五隊模式，總圈數須為 **4 的倍數**。15 或 30 隊且圈數合適時，兩種模式都可選。每隊使用一張實體桌，全員持續打牌，仍受 32 隊、31 圈、128 副不同牌號的上限限制。

每 2 圈（三隊）或 4 圈（五隊）是一個循環。各循環預設依名單順序分組，可在選單逐一調整；選擇隊伍時會與該循環的原位置互換，每隊恰好出現一次。不同循環可重新分組，同一循環內則維持分組。系統不自動避開跨循環曾遇過的對手，也不依排名自動配對。

例如六隊、三隊模式、4 圈：第一循環可分 A/B/C 與 D/E/F，第二循環改為 A/D/E 與 B/C/F。圈次畫面顯示 **1-1、1-2、2-1、2-2**；五隊模式顯示 **1-1 至 1-4，再接 2-1**。CSV 的 round 仍為連續整數 1、2、3……。

每隊固定一組南北搭檔與一組東西搭檔，兩組在不同桌同時打牌。循環內南北留桌，東西及牌組依完整賽程表移動，不可交換南北／東西搭檔，以免重打已見過的牌；新循環使用新牌組，可重新安排搭檔方向與桌號。

每圈牌數也是每場對戰的比較牌數。每個循環需 3 或 5 組新牌，各組隊伍使用相同牌號的複製牌。每兩圈取得正反方向成績後，按每場原訂牌數換算完整 WBF 20–0 VP，歸入較後的圈次。每隊每個三隊循環有 2 場、每個五隊循環有 4 場；不是半場折半 VP。

例如六隊、三隊模式、4 圈、每圈 8 副：需 48 副不同牌號、2 套複製牌，共 96 副實體牌，每位賽員打 32 副。單組三隊兩圈為 24 副、每位打 16 副；單組五隊四圈為 40 副、每位打 32 副。

圈次頁列出實際桌號、南北／東西隊伍與牌號，隊伍成績頁標示兩桌各自的圈次及桌號。「開／閉」僅區分比較方向，不代表兩間固定房間。同一副可能在其他組或後續圈次繼續使用，請等全場使用完再公開牌型或討論。

上述方式均由裁判收分；隊制賽尚未提供雙人賽的俱樂部手機確認流程，也尚無自動 Swiss 配對。

## 套用前看什麼

按「預覽完整賽程」，核對每圈對手、方向、牌號、總牌數以及所需複製牌。確認後會替換整個賽程、清除原圈次時間、重設為尚未開始。相同牌號的牌型保留，新增牌號的牌型為空，超出範圍的牌號移除。

已有成績、已有結算圈次或賽事已結束時不能套用。若是賽前重做測試資料，可由裁判使用「清除所有成績」；這會連帶清除扣分與結算狀態，請先匯出資料，不要在正式比賽中把它當作一般更正。

## CSV 自訂編排

先設定圈數、每圈牌數與牌號範圍，再匯出賽程 CSV 作為範本。可逐圈匯入完整桌次，但不能變更已收分圈次，也不能讓同對重打牌。雙冠軍編排不接受違反 NS／EW 分組的換向。

交錯循環 CSV 使用額外的 `matchId` 配對跨圈兩桌，須在收分前一次匯入全部循環的完整賽程；不支援逐圈覆寫。輪空編排匯出的 `byeVp` 欄保存輪空 VP，已有成績後不能用匯入改變它。輪空隊伍依各圈缺席名單判定，不另填虛擬桌次。

系統沒有自動 Swiss 配對；若採 Swiss，由主辦自行產生對戰再匯入。詳見[匯入格式](imports.md)。

## 牌型與發布

可匯入完整 PBN，或在「產生隨機牌局 PBN」填選用的 Deal Source 條件。隨機發牌最多 128 副、100 萬次嘗試、30 秒；未達條件會回報錯誤，可取消。套用牌型須含本賽段全部牌號，且尚未收分。

牌型不是收分的必要條件。公開前請在「圈次與發布設定」核對牌組；同組牌的公開設定會連動。俱樂部模式下，還須等該副所有安排圈次結算後才對觀眾顯示手牌。
