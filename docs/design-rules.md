# Valet 設計規則

本文件記錄已確認的產品設計決策。修改介面時先依此規則，再查閱 [色彩變數](colors.md)。使用者的新指示優先，變更決策時同步更新本文件。這是設計依據，不代表所有既有介面都已完成一致化。

## 文案與資訊層級

Avoid unnecessary secondary labels and descriptions. Let the layout do the explaining.

- 標題直接說明內容；不另加重述標題的副標或宣傳問句。
- 斜線用半形 `/`。短語並列不留空格，例如「輸入/確認」「完成/安排牌數」「裁判/賽務」「NS/EW」。兩側較長或含動態內容時，左右各留一格，例如「輸入 P6 / 確認 P4」。數量與進度一律留空格，例如「已收 3 / 15 副」「第 2 / 5 圈」。網址與路徑不留空格，例如「http/https」「localhost/127.0.0.1」。參賽姓名裡的斜線是儲存內容，半形與全形都接受，顯示時不改寫原字。
- 版面能表達的關係，不再用常駐說明重複解釋。
- 計算方法與進階細節放入共用按鈕開啟的 popover/dialog 或手冊。禁止在產品介面使用原生 HTML details/summary；主要內容用一般區段呈現，不用摺疊控制項隱藏。
- 單位、暫計、未公開、私下檢視與破壞性操作影響不能為了簡潔而隱藏。
- 完成覆核等正常完成操作不用警告色；刪除、清除等破壞性操作才使用危險操作樣式。
- 首頁賽事卡片的整體狀態只依未封存賽段計算。全部賽段都封存時顯示「已封存 · 僅裁判可見」；完全沒有賽段時仍顯示「尚未安排賽段」。

- 賽事填場館，學期寫入賽事名稱。主辦單位由通行碼機制指派，依賽段的主辦單位 ID 顯示名稱。賽段填賽場位置；顯示地點時以空格連接場館和賽場位置，只有一項時顯示該項。

## 色彩與元件來源

- 色票集中於 public/theme-colors.css；元件以用途變數取色，不散落主題色碼。
- 主題名稱：生成式藝術（forest）、傷眼睛（light）、租屋補助（sepia）、知識藍（nord）、ドパガキ（dracula）。主題名稱下的描述只簡短列主要配色。
- 外部牌桌的顏色由 app/styles/viewer-theme.css 轉接；花色主題規則另見 app/styles/theme-integration.css。新增規則前先查現有選擇器，避免持續堆疊覆寫。
- 「貼上賽段」依賽事列出來源，顯示一行賽制摘要。預設帶入設定／移位和名單；勾選成績時，同時勾選並鎖定設定／移位、名單和牌。
- 一般操作沿用共用按鈕；留言的回覆、刪除、管理採暱稱後的點分隔文字操作。沒有權限的操作不顯示。

## 花色依使用位置決定

| 位置 | 規則 |
| --- | --- |
| 四手牌 | 保留主題花色。知識藍使用縮小的粗體空心符號；ドパガキ使用實心四色。 |
| 牌桌四角 | Par、Table Result、雙夢家表頭全部用所在位置的文字原色，不做紅黑或四色著色。 |
| 出牌鍵盤 | 黑桃、梅花用文字原色；紅心、方塊用主題的 --suit-red。符號與牌點一致。 |
| 傷眼睛主題手牌 | 實心純黑/純紅；深色側欄的黑桃、梅花改用側欄文字色。 |
| 側欄、留言 | 遵循各自主題設定，不直接繼承危險操作色；不可誤套牌桌四角的單色例外。 |

ドパガキ四手牌：黑桃亮鈷藍 #7AA2FF、紅心珊瑚紅 #FF7F7F、方塊紫色 #BD93F9、梅花金黃 #F1D58C。色碼只在集中色票維護。

花色必須使用文字呈現，不能讓手機自動替換為彩色 emoji。實心 Unicode 花色輸出加上 U+FE0E；font-variant-emoji: text 作補充，不能只靠 CSS color。保留可存取名稱。

## 身價

- 姓名、座位標記及標題底色須表達同一身價狀態；底色採淡色，文字維持可讀性。
- ドパガキ無身價姓名使用冰藍色，與座位標記的 --theme-solid 一致；知識藍同樣使用該主題的 --theme-solid。
- 租屋補助無身價使用側欄藍色；有身價使用金色。不要因紅心/方塊恢復紅色而連帶改動身價金色。

## 數字與單位

- 隊制暫定 VP 在對戰與逐場成績旁標示「暫定」，已計入的隊伍總分旁標示「含暫定」。逐副成績推估的「暫計 VP」維持原用語與計分行為。

- 成績元件共用 components/score-value.tsx 與 lib/score-format.ts；緊湊小數由 components/compact-imp.tsx 呈現：小數縮小、加底線，視覺隱藏小數點；輔助閱讀仍讀到正常數值。
- 格式化只影響顯示，不改計算精度。
- K 棒適用於所有雙人賽編排，包含 Howell、Mitchell、匯入與任意賽程。累積依該對出牌順序排列：先圈次，同圈再依牌號。影線與全場起伏都以該副全部桌次計算，各桌可在不同圈打這副牌。隊制賽不顯示。
- K 棒明細順序：前值、本副後、全場起伏、最大分差。只有本副後依上升/下降著色，其餘文字原色。
- 前值、本副後、全場起伏顯示兩位小數；最大分差顯示整數。
- 明細省略 IMP，保留 %，百分號前留少量間距。右上累積分數始終保留 % 或 IMP。
- 座標軸明確標示單位；K 棒常駐提示未扣罰分。橫軸標示圈數，每圈一個數字，圈與圈之間用淡分隔線。明細與右上「截至牌」仍用牌號。
- 全場起伏為每桌相對 Datum 的 Butler IMP 絕對值加總；不平衡得分以 NS/EW 絕對值平均，每桌計一次，取消與人工平均分排除。
- 最大分差為最高與最低 Butler IMP 的差，不是原始分差；目前不平衡得分分 NS/EW 計算後取較大範圍。

## 版面與互動

- 隊制裁判分別設定 VP、合約、牌型的公開時機（手動公開／一圈打完公開／兩桌可比即公開），預設手動公開，並針對手動公開的項目各自顯示牌組按鈕。
- 使用內容容器寬度決定並列，不只看整個視窗寬度；卡片之間保留間距。
- 搭檔成績寬版：左側表格約七成，右側選擇搭檔與 K 棒約三成；不重複顯示左側標題與選單。窄版恢復表格上方標題與選單，圖表置下。
- 隊制逐副比較（含跨圈兩桌）固定先列「南北合約」、再列「東西合約」，依左欄第一支隊伍的座位方向排列。切換主隊/客隊視角時，兩欄對應的桌次互換。各欄顯示該隊實得分數與同方向的 Butler IMP。點合約欄選取該桌，點列上其他位置選取該隊坐南北的桌次。
- 逐副成績寬版：四手牌與討論上下排列在左，單副成績表在右；窄版依序堆疊。
- 四手牌每一門維持一列，字級高度不變。只有塞不進格子的那一列才收窄：先縮小牌張間距，仍超出才水平縮放字寬。排得下的手牌、花色顏色與方位格子維持原樣。
- 表格列 hover 與 K 棒同步；滑鼠離開後清除 hover/準備選取狀態，保留已選資料與鍵盤焦點的合理行為。
- 討論回覆使用縮排與連線，同層最後一則的連線在標頭收尾，不向下穿出。

## 收分合約輸入

手機收分卡的線位、花色、莊家與賭倍用可點的分段按鈕，不用系統下拉。1–7 同一列；Pass 單獨一列，不和線位混在一起。新的一副不預選合約；Pass 本身就是完整成績，並停用其餘欄位。賭倍是選填修飾，標籤為「賭倍（選填）」，同一列只放「賭倍（DBL）」與「再賭倍（RDBL）」兩顆按鈕並排滿該列。預設都不選，代表未加倍；點一下選取，再點取消，兩顆互斥。線位、花色、莊家與實得墩數齊全即可儲存。未加倍仍以原本的未加倍值計分。實得墩數以合約（線位 + 6）為準，中央是 −2、−1、=、+1、+2，左右換頁才出現更遠的墩數。少於 0 墩或多於 13 墩的結果不顯示。這一頁少於五個時，按鈕維持五個排滿時的寬度：兩側都有換頁鈕就置中，只有一側就靠著該換頁鈕排，不留空位。沒有下一頁就不顯示該側換頁鈕。範圍只標這一頁看得到的結果。尚未選擇線位時，中央五個與兩側換頁鈕仍顯示但停用。更換線位時回到中央頁，並重新選擇墩數。選取的按鈕用主題主色的淡底、主色文字與主色框，不加陰影；未選取維持淺框。花色用 `--entry-suit-red`/`--entry-suit-black`（傷眼睛不沿用手牌純紅），選取後仍保持花色。首引仍可留空。裁判收分與不平衡合約使用同一組按鈕。

## 通行碼

工作人員沒有個人帳號，也不使用第三方登入。站台管理員、主辦單位、賽事裁判、收分、唯讀、搭檔收分連結與選手個人碼分層簽發，只存雜湊。登入連結把碼放在網址片段，不放在 query string。細節見 [分層通行碼](access-codes.md)。

## 修改後核對

依修改範圍檢查手機與寬版、相關主題、一般與裁判權限，以及空資料/暫計狀態。花色與字型問題需包含 iPhone Safari 實機確認；桌面模擬與字串測試不能宣稱已驗證 iOS 顯示。不要為單純文案修改擴充不相關測試。

展示頁與截圖測試操作見 [視覺回歸](visual-testing.md)。

- K 棒以「累積 IMP/MP%」標題按鈕開啟計分說明 popover，貼近標題並限制在視窗內；底部不重複放說明入口。累積分數與寬版「查看搭檔」標題使用一致的 18px 字級。窄寬時標題與說明圖示保持同一行，右側累積分整塊換到下一行，字級與圖示大小不變。
