# Valet 設計規則

本文件記錄已確認的產品設計決策。修改介面時先依此規則，再查閱 [色彩變數](colors.md)。使用者的新指示優先，變更決策時同步更新本文件。這是設計依據，不代表所有既有介面都已完成一致化。

## 文案與資訊層級

Avoid unnecessary secondary labels and descriptions. Let the layout do the explaining.

- 標題直接說明內容；不另加重述標題的副標或宣傳問句。
- 版面能表達的關係，不再用常駐說明重複解釋。
- 計算方法與進階細節放入可展開的說明或手冊。
- 單位、暫計、未公開、私下檢視與破壞性操作影響不能為了簡潔而隱藏。
- 完成覆核等正常完成操作不用警告色；刪除、清除等破壞性操作才使用危險操作樣式。

## 色彩與元件來源

- 色票集中於 public/theme-colors.css；元件以用途變數取色，不散落主題色碼。
- 主題名稱：生成式藝術（forest）、傷眼睛（light）、租屋補助（sepia）、知識藍（nord）、ドパガキ（dracula）。主題名稱下的描述只簡短列主要配色。
- 外部牌桌的顏色由 app/styles/viewer-theme.css 轉接；花色主題規則另見 app/styles/theme-integration.css。新增規則前先查現有選擇器，避免持續堆疊覆寫。
- 一般操作沿用共用按鈕；留言的回覆、刪除、管理採暱稱後的點分隔文字操作。沒有權限的操作不顯示。

## 花色依使用位置決定

| 位置 | 規則 |
| --- | --- |
| 四手牌 | 保留主題花色。知識藍使用縮小的粗體空心符號；ドパガキ使用實心四色。 |
| 牌桌四角 | Par、Table Result、雙夢家表頭全部用所在位置的文字原色，不做紅黑或四色著色。 |
| 出牌鍵盤 | 黑桃、梅花用文字原色；紅心、方塊用主題的 --suit-red。符號與牌點一致。 |
| 傷眼睛主題手牌 | 實心純黑／純紅；深色側欄的黑桃、梅花改用側欄文字色。 |
| 側欄、留言 | 遵循各自主題設定，不直接繼承危險操作色；不可誤套牌桌四角的單色例外。 |

ドパガキ四手牌：黑桃亮鈷藍 #7AA2FF、紅心珊瑚紅 #FF7F7F、方塊紫色 #BD93F9、梅花金黃 #F1D58C。色碼只在集中色票維護。

花色必須使用文字呈現，不能讓手機自動替換為彩色 emoji。實心 Unicode 花色輸出加上 U+FE0E；font-variant-emoji: text 作補充，不能只靠 CSS color。保留可存取名稱。

## 身價

- 姓名、座位標記及標題底色須表達同一身價狀態；底色採淡色，文字維持可讀性。
- ドパガキ無身價姓名使用冰藍色，與座位標記的 --theme-solid 一致；知識藍同樣使用該主題的 --theme-solid。
- 租屋補助無身價使用側欄藍色；有身價使用金色。不要因紅心／方塊恢復紅色而連帶改動身價金色。

## 數字與單位

- 成績元件共用 components/score-value.tsx 與 lib/score-format.ts；緊湊小數由 components/compact-imp.tsx 呈現：小數縮小、加底線，視覺隱藏小數點；輔助閱讀仍讀到正常數值。
- 格式化只影響顯示，不改計算精度。
- K 棒明細順序：前值、本副後、全場起伏、最大分差。只有本副後依上升／下降著色，其餘文字原色。
- 前值、本副後、全場起伏顯示兩位小數；最大分差顯示整數。
- 明細省略 IMP，保留 %，百分號前留少量間距。右上累積分數始終保留 % 或 IMP。
- 座標軸明確標示單位；K 棒常駐提示未扣罰分。
- 全場起伏為每桌相對 Datum 的 Butler IMP 絕對值加總；不平衡得分以 NS／EW 絕對值平均，每桌計一次，取消與人工平均分排除。
- 最大分差為最高與最低 Butler IMP 的差，不是原始分差；目前不平衡得分分 NS／EW 計算後取較大範圍。

## 雙夢家試打提示

| 情境 | 顯示與底色 |
| --- | --- |
| 未代入桌次結果、莊家方出牌（含夢家） | 顯示莊家最終墩數；最高墩數全部綠底，其他紅底。 |
| 未代入桌次結果、防家出牌 | 顯示莊家最終墩數；最低墩數全部紅底，其他綠底。 |
| 代入 Table Result 的有效合約 | 顯示 -N／=／M；N 為宕約墩數，M 為超墩數。只有宕約紅底，完成及超墩綠底，不依出牌方改變。 |

## 版面與互動

- 使用內容容器寬度決定並列，不只看整個視窗寬度；卡片之間保留間距。
- 搭檔成績寬版：左側表格約七成，右側選擇搭檔與 K 棒約三成；不重複顯示左側標題與選單。窄版恢復表格上方標題與選單，圖表置下。
- 逐副成績寬版：四手牌與討論上下排列在左，單副成績表在右；窄版依序堆疊。
- 表格列 hover 與 K 棒同步；滑鼠離開後清除 hover／準備選取狀態，保留已選資料與鍵盤焦點的合理行為。
- 討論回覆使用縮排與連線，同層最後一則的連線在標頭收尾，不向下穿出。

## 修改後核對

依修改範圍檢查手機與寬版、相關主題、一般與裁判權限，以及空資料／暫計狀態。花色與字型問題需包含 iPhone Safari 實機確認；桌面模擬與字串測試不能宣稱已驗證 iOS 顯示。不要為單純文案修改擴充不相關測試。

展示頁與截圖測試操作見 [視覺回歸](visual-testing.md)。
